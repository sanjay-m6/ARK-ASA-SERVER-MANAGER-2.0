@everyone

# 🚀 v2.4.3 Stable Release — Support for ASA & ASE + Critical Fixes!

We are excited to announce the release of **v2.4.3 Stable**, bringing full production-ready support for both ARK: Survival Ascended (ASA) and ARK: Survival Evolved (ASE). We have officially removed the Beta tag!

**Download:** https://github.com/sanjay-m6/ARK-ASA-SERVER-MANAGER-2.0/releases/tag/v2.4.3

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 🔧 Critical Bugfix: ASA Config Mismatch (RCON & GCM Fixed!)
* **The Fix:** Resolved a path resolution issue where ASA server configuration files were written to the wrong directory.
* **The Result:** The server now correctly reads your configured admin password, query ports, and max player settings. **RCON connections and in-game admin commands (like `gcm` / Give Creative Mode) are now fully functional!**

### 📁 Custom Presets — Export & Import
* **Preset Sharing:** You can now save your custom configurations and export them as `.json` files.
* **Community Presets:** Easily import configurations shared by the community with one click.

### 🔌 CurseForge Mod URL Parser
* No need to track down raw mod IDs! Simply paste any CurseForge Mod URL directly into the Mod Input box, and the manager will automatically extract the ID.

### 🛠️ SteamCMD Error Recovery
* Encountering installation hiccups like SteamCMD Error 7? We've added a diagnostics panel with cache-clearing, error repairs, and one-click retries to get your installation back on track.

### 🌐 Translation Updates
* Added full support for **Traditional Chinese (繁體中文)**, including locale flags and a language selector dropdown.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

**How to Update:** 
Your manager should automatically download the update. If not, click the update banner in the app or download the latest `.msi` from the release link above to upgrade in-place. Thank you for your feedback during the beta!
