# Changelog - v2.3.5

## 🎉 Major Features

### Infinity AI Assistant
- Integrated an intelligent, autonomous AI assistant directly into the server manager.
- Features a real-time markdown-supported chat interface.
- Includes a secure tool-calling framework for autonomous server administration (status checks, backups, RCON commands, etc.).
- Built-in two-tier safety execution model ensuring manual user confirmation for all destructive actions.

### Visual Cluster Builder
- Added a brand new visual interface for managing server clusters.
- Easily link, unlink, and manage cross-ARK travel between your configured servers with an intuitive graphical interface.

### Seamless Background Auto-Updater
- Completely redesigned the application's update mechanism.
- **Silent Background Downloads:** Updates are now downloaded silently in the background without interrupting your workflow.
- **Glassmorphism Modal:** Once downloaded, a beautiful, centered glassmorphism UI modal will prompt you to restart the application to apply the update.
- **Settings Toggle:** Added a new "Automatic Background Updates" toggle switch in the Settings tab to easily enable or disable automatic updating.

## ✨ Enhancements & Additions
- **Community & Point System:** Added comprehensive tools to manage community members and a new player point system.
- **Tribe Log Viewer:** You can now view and search tribe logs directly from within the manager.
- **UPnP Panel Enhancements:** Improved the UPnP management panel for easier port forwarding configuration.
- **New Maps Support:** Added support for the latest released ARK: Survival Ascended maps.

## 🛠 Fixes
- Fixed issues where manual update checks were unresponsive or failing.
- Resolved type-checking and compilation warnings in the update-checker components.
