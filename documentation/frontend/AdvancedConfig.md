# ⚙️ Advanced Configuration

The Advanced Configuration hub is a surgical suite designed for power users and server administrators. It provides low-level control over the server's execution environment and features an integrated performance optimizer to minimize the manager's resource footprint.

## 📝 Page Overview
- **Route**: `/tools/advanced`
- **Purpose**: Custom launch argument orchestration, system-level process prioritization, and aggressive RAM optimization.
- **Aesthetic**: High-performance "Red & Orange" interface featuring monospaced command previews, technical diagnostic cards, and one-click performance presets.

## 🚀 Key Modules

### 1. Surgical Launch Orchestration (🚀)
Fine-tune your server's boot sequence:
- **Custom Argument Ingestion**: Directly define low-level command-line flags (e.g., `-NoBattlEye`, `-ServerPVE`) that are appended to the server executable. This enables features and optimizations not available in standard configuration menus.
- **Live Configuration Preview**: A real-time visualizer that combines your map selection with your custom arguments, allowing you to verify the final execution string before starting the server.
- **Interactive Preset Palette**: Access a curated library of "Quick Presets" for popular community maps and mods. For example, apply the complex argument chains for "Scorched Earth Reborn" with a single click.

### 2. Application Performance Optimizer (⚡)
Ensure your host machine remains responsive:
- **Manual RAM Trimming**: Instantly purge unused memory from the Server Manager application, freeing up every possible megabyte for your game servers.
- **Manager Priority Elevation**: Set the application's process priority to "High" within the operating system. This ensures the UI remains snappy and responsive even when your servers are under heavy load.
- **Ultra Eco Mode**: An aggressive, automated resource management system designed for low-memory environments. This mode targets an application footprint of less than 50MB, making it ideal for budget VPS hosting.

### 3. Diagnostic & Verification Tools (🔍)
Audit your technical configuration:
- **Configuration Forensics**: Use the "Active Configuration" card to see exactly how the server will interpret your settings. Includes map name tracking and argument verification.
- **Diagnostic Copy**: One-click "Copy to Clipboard" functionality for your active launch strings, perfect for sharing your setup with community support or technical forums.
- **Integrity Warnings**: Real-time safety alerts highlight the risks of incorrect launch arguments, helping you avoid boot failures caused by syntax errors.

### 4. Technical Workflow Optimization (🛠️)
Streamlined controls for rapid iteration:
- **Per-Server Settings Persistence**: Advanced arguments are saved independently for each server instance, allowing you to maintain different optimization profiles for different maps.
- **Instant Save Feedback**: Visual status indicators and toasts confirm that your advanced configurations have been successfully committed to the database.
- **System-Aware Controls**: Performance tools intelligently interface with the host OS to provide real-time optimization without requiring manual registry edits.

## 🛠️ Interface Controls
- **Custom Arguments [Input]**: Type or paste additional command-line flags.
- **Save Settings [Save]**: Commit your advanced launch configuration.
- **Optimize RAM [Eraser]**: Manually trigger a memory cleanup.
- **Priority Toggle [Bar Chart]**: Switch between Normal and High process priority.
- **Enable Eco Mode [Leaf]**: Activate aggressive background memory management.

## 🎨 Design Notes
- **Advanced Aesthetic**: Uses vibrant red and orange gradients to distinguish the "High-Risk/High-Performance" layer of server administration.
- **Technical Workspace**: Features monospaced fonts and semi-transparent panels to create a professional "Engineer's Console" environment.
- **Safety Highlighting**: Critical warnings are displayed with high-visibility amber icons to ensure important notices are never missed.
